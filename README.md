# Coffee-Shop-Sales

An interactive Excel dashboard analyzing coffee shop sales data
across multiple store locations, product categories, and time periods.

---

## Dashboard Overview

Built entirely in Microsoft Excel using Pivot Tables, Pivot Charts,
and Slicers, this dashboard provides a comprehensive view of coffee
shop performance across key business metrics.

---

## Key Metrics

| Metric | Value |
|---|---|
| Total Sales | $6,98,812.33 |
| Total Footfall | 1,49,116 |
| Avg Bill / Person | $4.69 |
| Avg Order / Person | 1.4 |

---

## Visuals Included

- **Quantity Ordered by Hours** — Line chart showing peak ordering hours
- **Categories % Distribution** — Pie chart across 9 product categories
  (Coffee, Tea, Bakery, Drinking Chocolate, etc.)
- **% Size Distribution Based on Orders** — Order size breakdown
  by store location (Astoria, Hell's Kitchen, Lower Manhattan)
- **Footfall & Sales by Store Location** — Bar chart comparing
  all 3 store locations
- **Top 5 Products by Sales** — Barista Espresso leads at $91,406
- **Orders on Weekdays** — Transaction volume across all 7 days

---

## Filters / Slicers

- **Month Name** — January through June
- **Day Name** — Monday through Sunday

##  How to Use

1. Download the `.xlsx` file
2. Open in Microsoft Excel (2016 or later recommended)
3. Go to the **Dashboard** tab
4. Use the **Month** and **Day slicers** on the left to filter
   the entire dashboard dynamically

---

## Key Insights

- **Barista Espresso** is the top-selling product at $91,406
- **Hell's Kitchen** and **Astoria** have nearly equal footfall
  (~50,700 each), with Lower Manhattan slightly lower
- Peak ordering hours fall between **9 AM – 11 AM**
- **Coffee** dominates category distribution at 39%
- Weekday orders are fairly consistent, ranging from ~20,510
  to ~21,701 transactions
